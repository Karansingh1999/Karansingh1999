### 🔐 [PIIFlow](https://github.com/Karansingh1999/PIIFlow)

<img src="https://img.shields.io/badge/STATIC_ANALYSIS-178579?style=flat-square" alt="Static analysis" />
<img src="https://img.shields.io/badge/LLM_DATA_SECURITY-315F86?style=flat-square" alt="LLM data security" />

A policy-aware Python analyzer for detecting sensitive-data flows into LLM APIs.

**Method:** Traces data from source to sink through application code, then evaluates provider, trust-zone, and sanitizer rules.

**Evaluation:** Reports **0.894 overall F1 across 90 synthetic flow cases**. The repository documents benchmark scope and limitations.

### ☁️ [CloudShift-RL](https://github.com/Karansingh1999/CloudShift-RL)

<img src="https://img.shields.io/badge/RESOURCE_ALLOCATION-6554A4?style=flat-square" alt="Resource allocation" />
<img src="https://img.shields.io/badge/REPRODUCIBLE_EVALUATION-315F86?style=flat-square" alt="Reproducible evaluation" />

A Gymnasium benchmark for testing resource-allocation policies as synthetic workloads change.

**Design:** Compares heuristic schedulers with a limited-compute DQN baseline across steady, burst, memory-shift, and node-failure scenarios.

**Evaluation:** Uses matched scenario and seed pairs, with a frozen experimental manifest and published results.
